GameZone

versão 3.0.0

Central de especificações, monitoramento em tempo real e biblioteca de jogos. Todos os dados de hardware são lidos via plugins nativos do Capacitor — sem APIs do navegador.

  • StackHTML · CSS · Vanilla JS
  • Device Info@capgo/capacitor-device-info
  • Apps@capgo/capacitor-android-usagestatsmanager
  • Orientação@capacitor/screen-orientation
⚠ Aviso

Para listar apps instalados, o APK precisa da permissão de uso do Android. O build injeta automaticamente QUERY_ALL_PACKAGES e PACKAGE_USAGE_STATS no AndroidManifest.xml.
